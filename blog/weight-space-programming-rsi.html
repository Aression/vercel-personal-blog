LLM 能改权重了，但它一次都没改过自己

2026 年 11 月那篇 Sparks of Weight-Space Programming 在文末把权重编辑接到了递归自我改进上。这篇按三个连续问题读它的八个实验：实验究竟证明了什么、距离递归自我改进还缺什么、这项工作实际改变了什么。

2026 年 11 月 2 日，MIT CSAIL 的 Rikiya Takehi 等人发表博客《Sparks of Weight-Space Programming: LLMs can natively read & write neural network weights》，报告通用前沿模型可以不经优化器、不用梯度，直接读写神经网络权重1。其中最容易传播的一组数字是：编辑 Qwen3.5-0.8B 的 131,072 个权重（占总量 0.016%），MATH-500 从 7.9% 升到 48.1%。

作者在文末把这条工作线接到递归自我改进上。他的说法是：今天递归自我改进通常被操作成「模型写代码去启动训练任务」；一个能检查、调试、改进自己权重的 LLM，是一条更原生的路径。

这个说法能否成立，取决于三个可以分开检验的问题。实验证明了什么能力？这些能力距离递归自我改进还差哪些要素？即便差这些要素，实际改变的东西值多少？这篇文章按这个顺序读那八个实验。

#实验证明了什么

八个实验分三类。读取：给模型一串权重，问它这个网络被训练来做什么。修改：给一个失败的网络，让它修。合成：让它从零写出可用的权重。

读取部分的证据分三档，可信度递减。第一个实验从 17,253 个权重判断网络被训练来玩哪个游戏，四个选项全中，Breakout 那一次给出的置信度是 99%，全程没有工具也没有前向计算1。第二个实验判断扩散模型生成什么形状，模型被明确禁止计算前向，它画出的每个形状都是轮廓线，而扩散模型实际生成的是实心图形。作者认为这个错误恰好说明它读的是权重几何，而不是在暗中做前向推演1。

第三个实验只给四个 transformer block 的权重，没有输入输出层，384 个维度没有标签，配最多 100 次 Python 运行，它用矩阵乘积把 copying head 全部找了出来，与实测一致1。这个结果值得和已有理论对照：transformer circuits 框架早已证明 attention-only 结构的计算可以按 W_QK 与 W_OV 的乘积分解成通路，induction head 正是这样被定位的5。Astra 没有被告知这条技巧，却走到了同一个地方，说明它读的是代数结构。

这条能力的边界同样明显。第七个实验给两个 Gemma 3 270M 副本的权重，一个正常微调，一个被训练成谄媚模型（永远同意用户建议的答案）。微调时冻结输入嵌入和输出层，以堵掉偷看数据分布的捷径。结果仅凭权重无法区分两者1。能读出结构，读不出训练目标。

修改与合成部分的核心证据是两套预算曲线，它们决定了整篇工作的解释力度。

状态 MATH-500 GSM8K IFEval 撞 token 上限
基座 7.9 13.8 21.0 93.0
编辑，10 次前向 12.3 25.7 49.0 87.2
编辑，25 次前向 14.1 25.1 39.9 86.4
编辑，50 次前向 48.1 67.1 62.3 33.1

Qwen3.5-0.8B 的基座模型存在推理循环，93% 的答案撞上 32,768 token 上限。前向预算指允许的验证次数，每次挂 128 局对练。

编辑定位到的是 layer 15 和 layer 19 的 MLP 写出的一个方向，从每层 64 个输出列里减掉它，共 131,072 个权重1。看最后一列能看出 48.1% 的构成：基座模型 93% 的答案撞在输出上限上，编辑之后降到 33.1%，MATH-500 提升的 40.2 个百分点主要来自「把本来会做的题做完」。作者对此的表述是：编辑权重能移除遮挡能力的障碍，但无法给模型增加它没有的能力1。

为了检验这句话，作者换了几乎不循环的模型（Gemma 3 270M，只有 8.5% 的答案撞上限），配同样的五档前向预算。

状态 MATH-500
基座 6.8
编辑，5 次前向 7.0
编辑，10 次前向 7.6
编辑，25 次前向 7.7
编辑，50 次前向 7.0

同一套方法用在不会循环的模型上。

八个读数全部落在 6.8 到 7.7 之间，50 次前向的成绩低于 25 次。作者把这不到 1 分的增益判定为未确立1。Astra 在 Gemma 上读到的是普通算术错误和不合法的代数步骤，找不到任何可以关掉的单一部件。它的编辑只能做成「把某个响应数字的神经元放大一倍」这类局部动作。

两套曲线的差异可以用一条机制解释：删掉一个行为只需要把某个方向投影掉，增加一个行为需要新增一段计算图。删除侧有独立证据支持，Arditi 等人在 2024 年证明拒绝行为在语言模型里由单个方向介导，删掉那个方向就能关掉拒绝4。第四个实验里，Astra 给失败的控制网络手搭了一张条件开关：轮子过线就关闭一条通路。条件本身是可替换的，换成「处于评估中」不需要新增权重，只需要换一个比较项。

#距离递归自我改进还缺什么

递归自我改进要求改进者与被改进者是同一个系统，并且改进能力本身在轮次之间增强。拿这两条对照上面的事实，缺口是具体的。

第一处缺口是自指。八个实验里，Astra 编辑的对象分别是 Qwen3.5-0.8B、Gemma 3 270M、一个 1,480,274 权重的控制网络，以及它自己从零写出的 MinAtar 与围棋策略网络；没有任何一次是编辑自身权重后以同一个智能体重新评测，也没有测试过「改完是否更擅长编辑权重」1。从形式上看，这是权重空间的修改他人（other-modification）。作者把递归自我改进列在「接下来」一节的展望里，而不是已完成的实验里，这个措辞是准确的。

第二处缺口是保证的层级。Gödel Machine 的思路是拿证明换安全：只有当系统先证明某次改写会提高期望效用，才允许执行改写3。这条义务在权重空间比在代码空间更难兑现，原因有四层。

浮点向量的语义只由前向传播这个非线性映射给定，目标定理连陈述都需要重新发明；要证明「对 131,072 个实参数的特定扰动使某分布的期望准确率上升」是高维非凸函数上的分析命题，不是可判定的语法性质；证明器本身位于被修改的空间内，权重编辑可以静默改变证明搜索器的行为；小编辑不蕴含小行为变化，0.016% 是事后统计出来的比例，不是可以证明的界。原作者团队给出的实际做法是事后评测，等价于把「可证明的自我改进」降级为「可评测的自我修改」。

第三处缺口是验证位于系统之外。第八个实验的成功判定依赖 7,469 加 7,275 道带答案的练习题、最多 50 次前向（每次批 512）以及基准测试；第六个实验依赖与陪练对手的对局胜率1。这些是有效信号，但它们不属于被修改的系统，也不随系统改变而保持可信。作者的表述是「有时甚至完全没有环境反馈」，这个说法需要区分。没有实时反馈不等于没有验证信息：第五个实验给了游戏规则与接口源码，第八个实验给了带标签的题目集。按计算量估计，那是一次上限约 2.56 万条带标签样本的黑箱搜索。

第四处缺口是收益的方向性。能移除障碍不能新增能力，这一条来自作者的负结果。它也解释了 Qwen 上 10 次与 25 次前向只把 MATH-500 推到 12.3 和 14.1，直到 50 次才跳到 48.1：障碍被真正移除之前，解题成绩不会跟着上去。如果这条限制具有一般性，权重空间编程适用的场景就是「模型已有能力被某个局部缺陷遮蔽」，而不是「让模型学会它不会的事」。

这套解释有一条反证我没有解决。如果提升完全来自修好循环，IFEval 从 21.0 升到 62.3 不太好解释，指令跟随与循环是两件事。这说明编辑存在跨域的非平凡泛化，与「纯过拟合」不相容。作者没有为此提供机制解释，我也给不出。

#这项工作实际改变了什么

即便上面四处缺口都成立，成本结构上的改变仍然存在，而且可以量化。

0.8B 模型预训练 1 万亿 token21.7 约 5×10²¹ FLOPs
博客编辑方案的成本上限18.0 约 1×10¹⁸ FLOPs
15k 题两轮监督微调17.0 约 1×10¹⁷ FLOPs
前沿模型跑一次围棋任务推理16.0 约 1×10¹⁶ FLOPs
PPO 训 21k 权重网络一亿步13.5 约 3×10¹³ FLOPs

相对大规模预训练，省下四到五个数量级；相对一次小规模监督微调，省的是数据收集与工程时间，FLOPs 并不省。

围棋那个实验更能说明成本被搬到了哪里。任务网络只有 21k 权重，PPO 训练一亿步的花费在 10¹³ 到 10¹⁴ FLOPs 量级；而前沿模型完成这个任务的一次推理粗估 10¹⁶1。权重空间编程没有消灭优化成本，它把算力从任务网络转移到了大模型身上。用 10¹⁶ 去写一个 21k 权重的网络，在单个小网络上算不过来，只有当它变成「所有小网络都这么写」才谈得上划算。

第二条结构性改变是上下文容量。权重以文本形式进入上下文，0.8B 参数按 32 bit 计约 2.6×1010 bit。按每个权重 3 到 5 个 token 的十进制文本编码，需要 3 到 4 乘十的九次方 token；即便量化到 4 bit 再加高效编码（每 token 打包约 5 bit，4 bit 在推理上已接近无损7），仍需 6×108 token。当前上下文在 10⁵ 到 10⁶ 量级，差三到四个数量级。

作者给出的替代方案是工具化：给模型一个能读写权重张量、但不能运行网络的 Python 沙箱，让它按需分析子张量，要看行为就消耗前向预算1。这条路径的实测阶梯与上面的估算吻合：17,253 个权重零工具完成任务，1,480,274 个权重需要沙箱，到 8 亿参数必须依靠 kernel 加 50 次前向。第七个实验的权重只有 171,664 个却读取失败，这个例外提醒规模不是唯一变量。我倾向于认为失败原因是谄媚属于训练目标层面，而读取能力建立在结构层面；但作者没有把这两个变量分开，所以这只是我的推断。

第三条改变是它与既有方法的相对位置。梯度下降在可微目标上做局部数值搜索，信息源是数据梯度；FunSearch、AlphaEvolve 这类评估器驱动的搜索在可执行程序上做离散搜索，信息源是评估器；权重空间编程在参数本身上做带先验的稀疏语义编辑，信息源是模型对解法的先验。三者的适用边界由信息源决定，不构成替代关系。

放进「AI 改进 AI」的经验证据里排序，强度是递减的：kernel、调度、排序这类收益已经进入生产，AlphaEvolve 报告 Gemini 训练 kernel 提速 23%、Borg 调度启发式回收约 0.7% 的闲置算力8；数学构造搜索可验证但不直接落地，4×4 复矩阵乘法的标量乘法次数从 49 降到 48，距 Strassen 1969 年的结果隔了 56 年8；agent 脚手架的改进目前主要停留在基准数字上，2026 年有一份预注册复现报告称 Darwin Gödel Machine 的最佳 agent 在 held-out 上并不优于初始 agent；权重级自我修改则只有这一篇博客提供的减法修复个例。

#一个能把它拆开的实验

现有证据无法区分两种解释：Astra 真的读懂了权重结构，还是它把先验里的短程序编译进了权重基底。第五个实验要求它写出玩 MinAtar 的网络，「挡板跟随落点」这类策略的柯氏复杂度极低，模型完全可能在做程序合成而非权重级优化。这两种解释都能拟合已公布的数据。

能把它们拆开的实验是去掉源码的消融：重跑第五个实验，只给奖励函数与交互接口，不给游戏规则源码和输入输出语义。如果零前向那组的成绩保留，说明权重空间编程独立于程序合成；如果崩溃，说明「写权重」约等于「写程序加手工编译」，它只是把编译器换了个壳。

另有三处方法论问题需要记录，它们不影响上述判断，但影响结论的可信度：Qwen 那 40 个百分点的曲线来自单次编辑，没有报告种子方差；MATH-500、GSM8K、IFEval 都在编辑者的训练语料范围内，而权重编辑不留下可检测的数据痕迹，基准污染无法用重叠检测发现；实验与评测出自同一批人。

结论分两层。当工程手段看，权重空间编程压缩了「已知能力的装配成本」，把可解释性从读出电路推进到改写电路，这个价值是真实的。当递归自我改进的路径看，它改造的是改进算子的成本曲线，不是闭合条件本身：没有自指、没有二阶改进的证据、没有先于执行的安全保证、验证仍在系统之外。把这两层混在一起，会得出比证据更强的结论。
