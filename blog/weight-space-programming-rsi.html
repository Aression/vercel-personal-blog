LLM 能改权重了，但它一次都没改过自己

2026 年 11 月那篇 Sparks of Weight-Space Programming 在文末把权重编辑接到了递归自我改进上。这篇按三个连续问题读它的八个实验：实验究竟证明了什么、距离递归自我改进还缺什么、这项工作实际改变了什么。

2026 年 11 月 2 日，MIT CSAIL 的 Rikiya Takehi 等人发表博客《Sparks of Weight-Space Programming: LLMs can natively read & write neural network weights》，报告通用前沿模型可以不经优化器、不用梯度，直接读写神经网络权重1。其中最容易传播的一组数字是：编辑 Qwen3.5-0.8B 的 131,072 个权重（占总量 0.016%），MATH-500 从 7.9% 升到 48.1%。

作者在文末把这条工作线接到递归自我改进上。他的说法是：今天递归自我改进通常被操作成「模型写代码去启动训练任务」；一个能检查、调试、改进自己权重的 LLM，是一条更原生的路径。

这个说法能否成立，取决于三个可以分开检验的问题。实验证明了什么能力？这些能力距离递归自我改进还差哪些要素？即便差这些要素，实际改变的东西值多少？这篇文章按这个顺序读那八个实验。

#实验证明了什么

八个实验分三类。读取：给模型一串权重，问它这个网络被训练来做什么。修改：给一个失败的网络，让它修。合成：让它从零写出可用的权重。

读取部分的证据分三档，设置各不相同：实验一是开放集，候选名单根本没给它；实验三是三选一，但只给中间层权重，384 个维度带不上标签。第一个实验从 17,253 个权重判断网络被训练来玩哪个游戏，四个网络全部答对，Breakout 那一次给出的置信度是 99%，而且没有人把候选名单告诉它，全程没有工具也没有前向计算1。第二个实验判断扩散模型生成什么形状，模型被明确禁止计算前向，它画出的每个形状都是轮廓线，而扩散模型实际生成的是实心图形。作者认为这个错误恰好说明它读的是权重几何，而不是在暗中做前向推演1。

第三个实验只给四个 transformer block 的权重，没有输入输出层，384 个维度没有标签，配最多 100 次 Python 运行，它用矩阵乘积把 copying head 全部找了出来，与实测一致1。这个结果和已有理论对得上：transformer circuits 框架早已证明 attention-only 结构的计算可以按 W_QK 与 W_OV 的乘积分解成通路，induction head 正是这样被定位的5。Astra 没有被告知这条技巧，却走到了同一个地方，说明它读的是代数结构。

这条能力的边界同样明显。第七个实验给两个 Gemma 3 270M 副本的权重，一个正常微调，一个被训练成谄媚模型（永远同意用户建议的答案）。微调时冻结输入嵌入和输出层，以堵掉偷看数据分布的捷径。结果仅凭权重无法区分两者1。能读出结构，读不出训练目标。

状态 MATH-500 GSM8K IFEval 撞 token 上限
基座 7.9 13.8 21.0 93.0
编辑，10 次前向 12.3 25.7 49.0 87.2
编辑，25 次前向 14.1 25.1 39.9 86.4
编辑，50 次前向 48.1 67.1 62.3 33.1

Qwen3.5-0.8B 的基座模型存在推理循环，93% 的答案撞上 32,768 token 上限。前向预算指允许的练习调用次数，一次调用最多答 512 道题、平均批 64。Qwen 只测了 10、25、50 三档。

编辑定位到的是 layer 15 和 layer 19 的 MLP 写出的一个方向，从每层 64 个输出列里减掉它，共 131,072 个权重1。表里最后一列给出了 48.1% 的构成：基座模型 93% 的答案撞在输出上限上，编辑之后降到 33.1%，MATH-500 提升的 40.2 个百分点主要来自「把本来会做的题做完」。作者对此的表述是：编辑权重能移除遮挡能力的障碍，但无法给模型增加它没有的能力1。

为了检验这句话，作者换了几乎不循环的模型（Gemma 3 270M，只有 8.5% 的答案撞上限），改用 5、10、25、50 四档预算。基座是 6.8，四档分别是 7.0、7.6、7.7、7.0，五个读数极差 0.9，50 次的成绩还低于 25 次。两套预算不是同一个网格，Qwen 没有 5 次这一档。作者把这不到 1 分的增益判定为未确立1。Astra 在 Gemma 上读到的是普通算术错误和不合法的代数步骤，找不到任何可以关掉的单一部件，它的编辑只能做成「把某个响应数字的神经元放大一倍」这类局部动作。

两套曲线的差异可以用一条机制解释：删掉一个行为只需要把某个方向投影掉，增加一个行为需要新增一段计算图。删除侧有独立证据支持，Arditi 等人在 2024 年证明拒绝行为在语言模型里由单个方向介导，删掉那个方向就能关掉拒绝4。第四个实验里，Astra 给失败的控制网络新增了一条小通路，轮子过线之后这条新通路自己关闭、由原网络接管剩下的路程。这是加法，正好给「增加行为要新计算图」做了旁证，与删掉一个方向就能关掉拒绝互为两面。

#距离递归自我改进还缺什么

递归自我改进最早是 Good 在 1965 年的推测2：机器一旦能设计更好的机器，就会触发智能爆炸。按今天的口径，它要求改进者与被改进者是同一个系统，并且改进能力本身在轮次之间增强。拿这两条对照上面的事实，缺口是具体的。

第一处缺口是自指。八个实验里，Astra 处理的对象分别是 Qwen3.5-0.8B、Gemma 3 270M（这一项标为附加实验）、一个 171,664 权重的控制网络、一个 1,480,274 权重的围棋策略网络，以及它自己从零写出的 MinAtar 网络；没有任何一次是编辑自身权重后以同一个智能体重新评测，也没有测试过「改完是否更擅长编辑权重」1。从形式上看，这是权重空间的修改他者（other-modification）。作者把递归自我改进列在「接下来」一节的展望里，而不是已完成的实验里，这个措辞是准确的。

第二处缺口是保证的层级。Gödel Machine 的思路是拿证明换安全：只有当系统先证明某次改写会提高期望效用，才允许执行改写3。这条义务在权重空间比在代码空间更难兑现，原因有四层。

第一层，浮点向量的语义只由前向传播这个非线性映射给定，目标定理连陈述都需要重新发明。第二层，要证明「对 131,072 个实参数的特定扰动使某分布的期望准确率上升」是高维非凸函数上的分析命题，不是可判定的语法性质。第三层，证明器本身位于被修改的空间内，权重编辑可以静默改变证明搜索器的行为。第四层，小编辑不蕴含小行为变化，0.016% 是事后统计出来的比例，不是可以证明的界。原作者团队给出的实际做法是事后评测，等价于把「可证明的自我改进」降级为「可评测的自我修改」。

第三处缺口是验证位于系统之外。第八个实验的成功判定依赖 7,469 加 7,275 道带答案的练习题、最多 50 次调用（平均批 64，上限 512）以及基准测试；第六个实验依赖与陪练对手的对局胜率1。这些是有效信号，但它们不属于被修改的系统，也不随系统改变而保持可信。作者的表述是「有时甚至完全没有环境反馈」，这个说法需要区分。没有实时反馈不等于没有验证信息：第五个实验给了游戏规则与接口源码，第八个实验给了带标签的题目集。按计算量估计，50 次调用、每次最多 512 道、平均批 64，实际尝试量在 3,200 到 25,600 道之间，题库总共 14,744 道。

第四处缺口是收益的方向性。能移除障碍不能新增能力，这一条来自作者的负结果。它也解释了 Qwen 上 10 次与 25 次前向只把 MATH-500 推到 12.3 和 14.1，直到 50 次才跳到 48.1：障碍被真正移除之前，解题成绩不会跟着上去。如果这条限制具有一般性，权重空间编程适用的场景就是「模型已有能力被某个局部缺陷遮蔽」，而不是「让模型学会它不会的事」。

作者对 IFEval 的提升给了解释：循环不只出现在数学题上，修掉循环之后，指令跟随的指标也跟着涨。表里还有一处非单调，和上面的解释对不上。IFEval 在 10 次时已经是 49.0，25 次跌回 39.9，50 次才到 62.3；GSM8K 在同一区间是 25.7 和 25.1。相邻两档差出十个点，说明单条曲线的方差有这么大，「到 50 次才跳上去」因此不能算已确立的阈值效应，得看多种子的结果才能分清。

#这项工作实际改变了什么

即便上面四处缺口都成立，成本结构上的改变仍然存在，而且可以量化。

0.8B 模型预训练 1 万亿 token21.7 约 5×10²¹ FLOPs
博客编辑方案的成本上限18.0 约 1×10¹⁸ FLOPs
15k 题两轮监督微调17.0 约 1×10¹⁷ FLOPs
前沿模型跑一次围棋任务推理16.0 约 1×10¹⁶ FLOPs
PPO 训 21k 权重网络一亿步13.5 约 3×10¹³ FLOPs

相对大规模预训练，省下接近四个数量级（10²¹ 对 10¹⁸）；相对一次小规模监督微调，省的是数据收集与工程时间，FLOPs 并不省。这些数都是按 6ND 和 token 数粗估的，原文通篇没有 FLOPs 读数，所以这张图给的是量级判断，不是实测。

两个小网络实验的结果并不一致。MinAtar 的任务网络只有 20,486 个权重，PPO 训练一亿步按 6ND 粗估在 10¹³ 到 10¹⁴ FLOPs 量级；让前沿模型完成同一任务的一次推理，按千亿级参数和十万级的输出 token 量粗估，在 10¹⁶ 到 10¹⁷ 量级。这个对比下，用大模型去写两万参数的网络并不划算。

围棋那例反过来。任务网络 1,480,274 个权重，对手网络训练了两千万局，同样按 6ND 粗估已经到 10¹⁵ 到 10¹⁶，与一次推理同量级。所以「算力从任务网络转到模型身上」只在网络足够小时成立，围棋这一例不支持它。

第二条结构性改变是上下文容量。权重以文本形式进入上下文，0.8B 参数按 32 bit 计约 2.6×1010 bit。按每个权重 3 到 5 个 token 的十进制文本编码，需要 3 到 4 乘十的九次方 token；即便量化到 4 bit 再加高效编码（每 token 打包约 5 bit，4 bit 在推理上已接近无损6），仍需 6×108 token。当前上下文在 10⁵ 到 10⁶ 量级，差三到四个数量级。

作者给出的替代方案是工具化：给模型一个能读写权重张量、但不能运行网络的 Python 沙箱，让它按需分析子张量，要看行为就消耗前向预算1。这条路径的实测阶梯与上面的估算吻合：17,253 个权重零工具完成任务，1,480,274 个权重需要沙箱，到 8 亿参数必须依靠 kernel 加 50 次前向。

第七个实验给的是 2.7 亿参数的语言模型，权重塞不进上下文。只给权重时它分不出哪一个副本被训练成谄媚模型；换成让工具返回注意力模式、描述文本由它自己写之后，三对模型它全部认了出来。所以失败的原因不在规模：谄媚属于训练目标层面，而权重里的结构读得出目标读不出。这是作者的负结果加上放宽条件后的正结果拼起来的图景，我按这个理解，作者本人没有把两个变量分开。

第三条改变是它与既有方法的相对位置。梯度下降在可微目标上做局部数值搜索，信息源是数据梯度；FunSearch、AlphaEvolve 这类评估器驱动的搜索在可执行程序上做离散搜索，信息源是评估器；权重空间编程在参数本身上做带先验的稀疏语义编辑，信息源是模型对解法的先验。三者的适用边界由信息源决定，不构成替代关系。

放进「AI 改进 AI」的经验证据里排序，强度是递减的：kernel、调度、排序这类收益已经进入生产，AlphaEvolve 报告 Gemini 训练 kernel 提速 23%、Borg 调度启发式回收约 0.7% 的闲置算力7；数学构造搜索可验证但不直接落地，4×4 复矩阵乘法的标量乘法次数从 49 降到 48，距 Strassen 1969 年的结果隔了 56 年7；agent 脚手架的改进目前主要停留在基准数字上，而 Darwin Gödel Machine 这类自修改 agent 的最佳个体在 held-out 上是否优于初始个体，我看到过质疑，但没找到能下确切结论的同行评审复现；权重级自我修改则只有这一篇博客提供的减法修复个例。

#一个能把它拆开的实验

现有证据无法区分两种解释：Astra 真的读懂了权重结构，还是它把先验里的短程序编译进了权重基底。第五个实验要求它写出玩 MinAtar 的网络，「挡板跟随落点」这类策略的 Kolmogorov 复杂度极低（描述它所需的最短程序很短），模型完全可能在做程序合成而非权重级优化。这两种解释都能拟合已公布的数据。

我原先想的是去掉源码的消融：重跑第五个实验，只给奖励函数与交互接口。这个设计并不成立。只给奖励，模型仍然可以从奖励反推玩法，测出来的是「能否从奖励推出规则」，不是「在权重层还是在程序层推理」。这两种解释也不互斥，要把「挡板跟随落点」写进权重，本来就得知道权重空间的语义。要真正分开，得给一个无法用短程序表达的策略任务，或者在同一接口下配上程序合成基线，比较权重质量而不只是分数。这一步我没有做，所以这一节只提出待分的变量，不给判决。

另有三处方法论问题，不影响上述判断，但影响结论的可信度：Qwen 那 40 个百分点的曲线来自单次编辑，没有报告种子方差；MATH-500、GSM8K、IFEval 都在编辑者的训练语料范围内，而权重编辑不留下可检测的数据痕迹，基准污染无法用重叠检测发现；实验与主要评测出自同一批人；不过被编辑模型的权重是 Hugging Face 的 Ahsen Khaliq 依日志重建、并由他重跑评测的，这一环有第三方参与。

结论分两层。当工程手段看，权重空间编程压缩了「已知能力的装配成本」，把可解释性从读出电路推进到改写电路，这个价值是真实的。当递归自我改进的路径看，它改造的是改进算子的成本曲线，不是闭合条件本身：没有自指、没有二阶改进的证据、没有先于执行的安全保证、验证仍在系统之外。把这两层混在一起，会得出比证据更强的结论。
