关于

一个在上海写代码的人。

在上海，白天写 Agentic RL 和 AI Infra——agent 的上下文与记忆、本地推理栈、RL 训练与推理基础设施那一摊；晚上大概率在折腾什么小工具。

重庆大学计算机技术硕士（2026 届），本科也在重大。研究生阶段做计算机视觉：长尾识别、半监督目标检测、医学影像，一作发过 ICASSP、共一发过 Pattern Recognition，两项发明专利。现在把重心挪到 Agent 与系统方向。

最近折腾的四件事：给 agent 做证据化的长期记忆（压缩之后只交回仍然成立的发现）、给 AGI 进展做一张不许被新闻头条带跑的证据看板、在 AMD 卡上搭一整套 ROCm/HIP + KVMem 的本地推理栈并给上游打了几个补丁、以及把「读论文」这件事本身工程化成一座 Agentic RL 知识库。项目页有全部。

工程上是个自动化强迫症：能脚本化的绝不手动，爱折腾本地工具链和性能调优。偶尔为了搞懂原理，会把底层的东西自己实现一遍——RPC 框架、推理后端、甚至这个站点的排版。
